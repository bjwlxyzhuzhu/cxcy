# 🎮 创新创业 · 复杂游戏设计方案 v1

> 目标：从"网页小玩具"升级为**街机/引擎级**的真正复杂游戏。
> 五个品类：射击 · 祖玛 · 连连看 · 俄罗斯方块 · 跑酷闯关。
> 保留「创新创业」主题做差异化包装，兼顾大赛展示性与教学性。

---

## 〇、和上一版的本质区别

| 维度 | 上一版（简单网页游戏） | 本版（复杂游戏） |
|---|---|---|
| 渲染 | DOM 元素 + CSS | HTML5 Canvas，逐帧绘制 |
| 循环 | 事件驱动（点一下算一下） | 实时游戏循环（每秒 60 帧） |
| 核心难点 | 几乎没有 | 碰撞 / 物理 / AI / 路径 / 弹幕 / 状态机 |
| 代码量 | 100~300 行 | 800~2500 行/款（含引擎复用） |
| 手感 | 静态 | 帧同步、缓动、粒子、屏震、音效 |

---

## 一、共享技术底座（搭一次，五款复用）

所有游戏共用一套轻量自研引擎模块，避免重复造轮子：

| 模块 | 作用 | 关键点 |
|---|---|---|
| **GameLoop** | 主循环 | 固定时间步长(fixed timestep + accumulator) 更新物理，rAF 插值渲染，保证不同帧率手感一致 |
| **StateMachine** | 场景状态 | 菜单 / 游戏中 / 暂停 / 结算 切换 |
| **Input** | 输入抽象 | 键盘 + 鼠标 + 触屏统一成一套虚拟按键 |
| **Pool** | 对象池 | 子弹/敌人/粒子复用，杜绝 GC 卡顿 |
| **Particles** | 粒子系统 | 爆炸、拖尾、消除碎片、得分飘字 |
| **Audio** | 音频 | WebAudio，BGM + 音效池，可叠加播放 |
| **Camera** | 摄像机 | 跟随、边界、屏幕震动(screen shake) |
| **Save** | 存档 | localStorage 存最高分/解锁（**必须 try/catch 包裹、避免顶层调用**，否则在某些沙箱/隐私模式下会崩页） |

> ⚙️ 技术取舍：全部用**原生 Canvas + JS**，单文件或 `engine.js + game.js` 双文件，双击即玩、零依赖、零构建。如需更重的可后续上 PixiJS/Phaser。

## 二、五款游戏详细设计

### 1️⃣ 射击类 ——《创业突围战 · STARTUP BREAKOUT》

**🎯 主题映射**
你驾驶"创业飞船"，穿越 5 个融资阶段（天使 → A → B → C → IPO）的弹幕火网突围。
敌人 = 山寨竞品、市场谣言、资金链断裂的"债务弹"；每关 Boss = 一家行业巨头。

**🔁 核心循环**
走位躲弹幕 → 射击/蓄力 → 拾取掉落（💰融资=火力升级 / 👥人才=僚机 / 🛡️专利=护盾）→ 连击攒能量 → 放大招清屏 → 打 Boss 多阶段 → 过关。

**🧩 复杂系统**
- **参数化弹幕引擎**：直线 / 扇形 / 螺旋 / 追踪 / 花瓣，用极坐标函数生成，可叠加组合（弹幕游戏的灵魂）
- **敌人波次编排**：时间轴脚本驱动 spawn，编队入场
- **武器升级树**：散射 / 激光 / 导弹 三线，每线 3 级
- **僚机系统**：跟随插值 + 自动索敌开火
- **Boss 三阶段**：血量阈值切换攻击模式，残血进入狂暴
- **连击倍率 + 能量大招**：满槽放清屏弹或无敌冲刺
- **打击感(juice)**：屏震、命中顿帧、爆炸粒子、伤害飘字

**📈 难度曲线**：5 关，弹速/弹量/敌血逐关递增；判定用更小的"判定点"（参考东方 Project，擦弹更爽）。
**🛠️ 技术要点**：数千发子弹用对象池；圆形碰撞 + 网格/四叉树做宽相位加速。
**复杂度**：★★★★☆（弹幕引擎是难点）　**可玩 MVP 工作量**：中-高

### 2️⃣ 祖玛类 ——《资源链 · RESOURCE CHAIN》

**🎯 主题映射**
一长串"资源宝珠"（💰资金 / 👥人才 / ⚙️技术 / 📊流量 / 📜政策）沿轨道滑向尽头的"破产黑洞"。你在中心发射宝珠，凑齐 3 颗以上同色 = "整合资源"消除。珠子滑到终点 = 公司倒闭。

**🔁 核心循环**
看来珠颜色 → 瞄准角度发射 → 插入珠链 → 触发 3 连消除 → 间隙收拢二次连锁 → 拾取特殊珠 → 阻止珠链抵达终点。

**🧩 复杂系统**
- **轨道 = 贝塞尔/样条曲线**：珠子按"弧长参数"等距排布并整体推进
- **插入物理**：发射珠飞行 → 撞上珠链 → 计算插入点 → 撑开珠链重排
- **连锁崩塌**：消除后两段珠链回拢碰撞，可二次触发 combo
- **倒退物理**：消除后珠链向回缩的运动
- **特殊珠**：炸弹珠(爆款·范围清) / 倒退珠(回炉) / 慢速珠(融资到账) / 同色炸
- **多轨道 + 交叉 + 隧道遮挡**
- **危险区**：临近终点变红 + 心跳音效

**📈 难度曲线**：关卡 = 不同轨道形状与长度，珠速与种类递增。
**🛠️ 技术要点**：曲线预采样成密集点 + 累积弧长查找表；珠链存"距起点距离"，插入是 O(n) 重排；同色段用并查集式扫描；连锁用队列。**五款里算法最硬的一款。**
**复杂度**：★★★★★（路径物理 + 插入重排最难）　**工作量**：高

### 3️⃣ 连连看类 ——《商业版图连连看 · BIZ-LINK》

**🎯 主题映射**
棋盘铺满创业要素图标（产品 / 市场 / 团队 / 资金 / 专利 / 用户…）。找出能用"不超过 2 个拐角"的折线连通的同类两张 = "资源对接"，消除整盘。

**🔁 核心循环**
扫视全盘 → 选两张同图标 → 系统判定可连(≤2 折) → 画折线消除 → 触发重排 → 连击 → 清盘过关。

**🧩 复杂系统**
- **≤2 拐角路径判定**（核心算法）：枚举"直连 / 单拐 / 双拐"三类折线，检测沿途格子是否全空
- **死局检测**：每步后扫描是否还存在可消对，无解则**自动洗牌（且保证必有解）**
- **提示系统**：高亮一对可消
- **四种重力重排**：消除后向下 / 向上 / 左右 / 向心 收拢——按关卡切换，**极大改变难度**
- **限时 + 连击倒计时**
- **进阶机制**：会移动的方块、雾区(图标隐藏靠记忆)、旋转棋盘
- **关卡布局**：不同形状的盘面

**📈 难度曲线**：静态盘 → 重力盘 → 移动盘 → 雾区盘 递进。
**🛠️ 技术要点**：网格四周留一圈空格便于绕边走线；洗牌用"配对回填"保证有解；连线分段动画。
**复杂度**：★★★☆☆（算法中等，系统打磨多）　**工作量**：中

### 4️⃣ 俄罗斯方块类 ——《独角兽大厦 · UNICORN TOWER》

**🎯 主题映射**
每个方块 = 公司部门模块（研发 / 市场 / 财务 / 运营 / HR…）。把它们一层层垒成大厦；填满一整行 = 盖好一层楼并消除。楼越高估值越高，目标盖到"IPO 敲钟层"。

**🔁 核心循环**
预览下一块 → 移动/旋转/软降/硬降 → 锁定 → 满行消除/连击 → 重力加速 → 冲击楼层目标。

**🧩 复杂系统**（现代 Tetris 全套标准）
- **SRS 旋转系统 + 踢墙表(wall kick)**，含 T-Spin 判定
- **7-bag 随机器**：保证 7 种方块均衡出现
- **Hold 暂存 / Ghost 落点预测 / Next 预览 5 个**
- **软降 / 硬降 / 锁定延迟(lock delay)**
- **计分系统**：单/双/三/Tetris、Combo、Back-to-Back、T-Spin 加成
- **等级与重力曲线**：消行越多下落越快
- **🎁 主题彩蛋系统**：随机"事件方块"——黑天鹅(打乱) / 政策利好(直接消底行) / 资本注入(加速但高分)；"部门协同"奖励(特定颜色相邻额外加分)

**📈 难度曲线**：经典的"越快越难" + 事件方块增加变数。
**🛠️ 技术要点**：棋盘二维数组；方块用旋转状态矩阵 + 偏移踢墙表；重力计时器 + 锁延迟状态机；消行后整体下移。**规则最成体系、确定性最强，最适合作为第一款落地、也是验证共享引擎的试金石。**
**复杂度**：★★★★☆（系统多但可靠）　**工作量**：中-高

### 5️⃣ 跑的快闯关类 ——《创业马拉松 · THE FOUNDER'S RUN》

**🎯 主题映射**
创始人横版奔跑闯关：跳过"资金缺口 / 竞品陷阱 / 政策红线"，下滑钻过"行业壁垒天花板"，沿途收集 💰融资 / ⭐用户 / 🚀机遇，闯过各融资轮检查点，终点是"上市钟"。

**🔁 核心循环**
加速前进 → 跳跃/二段跳/下滑/冲刺 躲障碍 → 收集资源 → 检查点存档 → 用资源买永久升级 → 速度渐快 → 通关或刷分。

**🧩 复杂系统**
- **真·平台物理**：重力、跳跃抛物线、可变跳跃高度(长按跳更高)、土狼时间(coyote time)、跳跃缓冲(jump buffer)、二段跳、冲刺
- **关卡生成**：手工关卡 + 程序化拼段（预制段随机拼接）
- **视差滚动背景**：多层远近景
- **收集经济 → 商店升级树**：跳跃力 / 磁铁 / 护盾 / 复活
- **危险多样**：地刺 / 移动障碍 / 塌陷平台 / **身后追逐墙(资金链断裂在追你)**
- **角色动画状态机**：跑/跳/滑/受击 + 受击无敌帧
- **关底 Boss 门 = 路演冲刺**：一段高密度障碍

**📈 难度曲线**：速度递增 + 障碍密度 + 身后追逐墙逼迫节奏。
**🛠️ 技术要点**：固定步长物理；AABB 与单向平台碰撞(可下穿上踩)；相机跟随 + 边界；段落式 spawn 管理 + 对象回收。
**复杂度**：★★★★☆（手感打磨是关键）　**工作量**：中-高

## 三、推荐落地顺序（先易后难、先稳后炫）

1. **《独角兽大厦》(Tetris)** — 规则确定、最可靠、出效果快 → 作为引擎试金石。
2. **《创业突围战》(射击)** 或 **《创业马拉松》(跑酷)** — 视觉冲击强，最适合大赛现场演示。
3. **《商业版图连连看》** — 算法中等，稳扎稳打。
4. **《资源链》(祖玛)** — 路径物理最难，留到引擎成熟后再啃。

> 每款都建议先做 **可玩 MVP**（核心循环 60 帧跑通），再分层叠加：系统 → 关卡 → juice(粒子/屏震/音效) → UI/排行榜。
