# 创新创业基础在线习题库 1000题

本资源为可离线运行的 H5 在线题库。打开 `index.html` 即可使用，不需要安装服务器。

## 题库结构

- 总题量：1000题
- 题型：600道单选题、200道多选题、200道判断题
- 模块：10个课程模块，每个模块100题

## 课程模块

1. 创新创业认知与课程导论
2. 机会识别与区域产业
3. 用户调研与需求验证
4. 商业模式与价值主张
5. 市场分析与竞品定位
6. AI赋能创新与智能体应用
7. 项目计划、团队与执行
8. 财务、融资与成本收益
9. 知识产权、伦理与合规
10. 竞赛转化、路演与成果表达

## 功能

- 学生输入学号、姓名后开始答题。
- 支持练习模式：可查看本题解析，适合课堂训练和自主学习。
- 支持测试模式：倒计时结束自动交卷，交卷后统一显示成绩和解析。
- 支持按模块抽题、随机抽题、顺序练习。
- 交卷后显示总分、正确题数、用时、模块正确率和逐题解析。
- 可复制成绩摘要，也可下载成绩 JSON 文件。

## 建议使用

- 课前：选择对应模块20题进行预习诊断。
- 课中：教师投屏练习模式，针对错题讲解概念。
- 课后：测试模式抽取50题或100题，作为过程性评价。
- 竞赛训练：选择“竞赛转化、路演与成果表达”模块进行答辩前巩固。
