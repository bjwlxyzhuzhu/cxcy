# 创新创业基础 H5闯关训练营

这是一个离线可运行的 H5 小游戏合集，面向《创新创业基础》课程使用。

## 入口

直接用浏览器打开：

`index.html`

## 包含的10个小游戏

1. 机会雷达：训练创业机会识别。
2. 用户画像配对：训练用户和痛点匹配。
3. 商业画布拼图：训练商业模式画布归类。
4. 竞品定位矩阵：训练创新度与可行性判断。
5. AI伦理守门员：训练AI使用、隐私和版权意识。
6. 成本收益模拟器：训练收入、成本、利润和毛利率理解。
7. 问卷修正工坊：训练调研问卷设计。
8. 知识产权快判：训练软著、专利、外观设计判断。
9. 陕西产业地图：训练区域产业和选题匹配。
10. 路演答辩急救：训练评委追问应对话术。

## 课堂用法

- 课前预习：学生自行完成1到2个小游戏。
- 课堂互动：按小组PK，总分可复制到课程群。
- 课后复盘：让学生把错误题对应到课程笔记和项目材料。

## 技术说明

- 纯静态HTML，不需要服务器。
- 支持手机和电脑浏览器。
- 使用localStorage保存分数。
- 所有图形为页面内自制SVG/CSS图形，不依赖外部素材。
