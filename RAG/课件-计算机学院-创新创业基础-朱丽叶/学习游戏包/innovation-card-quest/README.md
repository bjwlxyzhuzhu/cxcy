# 创新创业基础卡牌闯关游戏

这是一个可离线运行的 H5 课堂互动游戏，围绕《创新创业基础》课程设计。打开 `index.html` 即可使用，不需要安装服务器或额外依赖。

## 游戏结构

- 8 个课程关卡：从机会识别、用户调研、商业画布、AI 工具应用，到大创申报、挑战杯路演和商业闭环。
- 16 张行动卡：机会雷达、用户访谈、问卷量表、竞品拆解、MVP 原型、商业画布、AI 智能体、数据核验、伦理合规、知识产权、第三方检测、应用证明、成本收益、团队分工、路演证据链、社会价值。
- 每关选择指定数量的行动卡，系统按课程逻辑自动评分。
- 单关 60 分以上解锁下一关，成绩保存在本机浏览器。

## 课堂用法

1. 教师先讲解本关场景。
2. 学生小组讨论后选择行动卡。
3. 提交后根据反馈复盘：哪些行动是关键证据，哪些行动过早或偏离目标。
4. 通关后复制成绩，用于课堂积分、小组展示或课后反思。

## 建议教学环节

- 理论课：用于导入“机会识别、商业模式、创新伦理、知识产权”等知识点。
- 实践课：用于项目路演前的快速诊断。
- 竞赛训练：用于大创、挑战杯、中国国际大学生创新大赛项目的证据链梳理。
