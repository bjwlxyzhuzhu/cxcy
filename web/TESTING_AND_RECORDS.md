# 课堂测试与记录功能

本次交付是源代码。导出文件由网站运行时生成，原始学生测试材料不在仓库中。

## 学生使用

1. 使用原账号登录，在各模块正常对话。发送的原话先保存，AI回复随后保存到同一记录。
2. 从“我的测试记录”查看历史、下载或继续对话；模块内也会恢复最近的同名练习。
3. “新建练习”创建新的记录，不删除旧记录。退出登录只移除登录凭据，不删除学习记录。
4. 驾驶舱从“历史记录”查看完整过程，可将历史的最后输出恢复到草案继续修改。

原版只存在网页内存且已经消失的对话无法恢复。旧版已保存的项目、成长证据及实验事件保留，不伪造缺失原话。未提交的普通对话输入不等于已保存记录；课堂实验输入有单独的本地和云端草稿。

## 新版课堂实验

教师在后台“课堂实验”创建实验、分享实验码和 `/experiment` 地址、点击“开放实验”。学生不需在驾驶舱、专家打磨和模拟答辩页面之间跳转。课堂建议约40—50分钟，但系统不按时钟强制清空或切换。

流程：前测 → 项目导读 → 初步方案V0 → 专家打磨5轮及修改版V1 → 模拟答辩3题 → 后测 → 体验反馈 → 查看与导出。

- A组沿用原代码的综合专家，B组沿用五位专家。按加入顺序交替分配，不是随机分组，也不据此宣称因果效果。
- 两组使用相同核心问题，每轮只显示一个问题。专家身份由服务端确定，解释与回答框架可按需求助。
- 本版为初学者流程，不继续执行旧版的多次强制追问。问题来自固定协议题库；AI负责解释和反馈，不能在前后测提供答案。
- 回答、跳过、求助和AI内容分别记录。完成问答步骤不代表回答质量合格，能力评分默认NULL，不将未完成计为0分。
- 前后测共同记录判断、两个关键条件、风险和1—5分把握程度。后测的观点变化及体验反馈独立保存，不计算混合总分。
- 登录后加入会关联账号，同账号同实验再次加入恢复原参与者；匿名参加需保存恢复码。恢复码是个人访问凭据，不进入研究导出。
- 旧实验使用 `legacy-v1` 标识，仍可查看和导出。请新建实验使用 `guided-v2`，不会覆盖旧分组和事件。

## 管理员查看

“学生管理”显示每个账号的对话数量、实验次数和在线状态，点击记录链接进入该学生的记录列表。“课堂实验”提供实验选择、进度汇总、前后测缺项、个人事件详情及导出。匿名参与者按固定编号显示，无法推断真实账号。

在线状态的定义：页面可见时每45秒发送一次心跳，服务端最近2分钟有登录或心跳即显示“近期在线”；后台每30秒刷新。仍有有效登录会话但超过2分钟未活动，显示“已登录，暂未活动”。退出全部会话后显示“已离线”。多个设备按任一有效会话判断，最后活动时间保留。此状态不代表学生持续注意或正在回答。

## 导出与数据结构

学生记录、各实验模块、个人完整实验、管理员课堂记录和研究数据都支持 DOCX、RTF、XLSX、PDF、CSV、JSON、Markdown。DOCX、RTF为真正对应格式；没有将HTML改名冒充DOCX。原有旧版 `.doc` 内容按钮保留兼容，新测试记录使用统一导出入口。

- `learning_sessions` 绑定账号、模块与练习；`learning_records` 保存完整原话、AI回复、附件文本及模型来源。图片仅记录名称，不宣称保存图片原件。
- `experiment_participants.participant_code` 是稳定编号；`experiment_events` 保存阶段、问题、角色、轮次、回答状态、请求编号及时间；`experiment_drafts` 保存未提交草稿。
- Excel/CSV 将嵌套字段展开，超过30000字符的文本按 `record` / `part` 分段，避免Excel单元格上限造成截断。JSON保留原结构。
- 研究导出只纳入同意研究的账号/实验参与者，编号不随排序变化。学生自行在自由文本输入的身份信息仍需研究者发布前复核。
- 管理教学导出包含账号，研究导出移除结构化姓名、学号和恢复码。历史问卷不按序号、IP或文件数量自动配对。

## 更新运行环境

沿用原项目 PostgreSQL、Next.js 和 GitHub Actions Docker流程。无新增外部服务账号。

```bash
cd web
pnpm install --frozen-lockfile
pnpm migrate
pnpm build
pnpm start
```

新增迁移 `0012_learning_records.sql` 与 `0013_presence.sql`，为追加表/字段，不删除旧数据。容器原有启动脚本会执行迁移。非容器启动需先设置 `DATABASE_URL` 并执行 `pnpm migrate`。回退旧代码时可以保留新表；不要删除记录表。部署前按原数据库备份流程操作。

Docker运行层增加 `font-noto-cjk`。非Docker Linux需要安装中文字体或设置 `EXPORT_PDF_FONT`；TTC集合字体可以用 `EXPORT_PDF_FONT_FAMILY` 指定字体名称。Windows默认使用系统宋体。缺少中文字体时PDF接口明确报错，不生成乱码文件。

## 验证

Windows未开启符号链接权限时，可在PowerShell设置 `$env:NEXT_DISABLE_STANDALONE='1'` 后构建并运行本地生产测试。默认配置仍生成Docker所需的standalone产物，GitHub/Linux构建不要设置此变量。

```bash
pnpm typecheck
pnpm test
pnpm test:integration
pnpm build
```

`pnpm test` 检查协议门槛、数值范围、历史迁移及七种导出格式，DOCX/PDF/XLSX会回读内容。PDF测试需要中文字体。

`pnpm test:integration` 启动隔离PGlite数据库和本地AI替身，调用真实Next.js HTTP接口，验证登录、退出恢复、跨账号隔离、幂等、草稿、阶段限制、8轮问答、前后测配对、后台记录、在线状态及导出。仅占用本机3318、3319、55439端口，不连接生产数据库，不调用付费AI。设置 `TEST_PRODUCTION=1` 可在 `pnpm build` 后验证生产构建。此测试不能代替真实模型的教学效果评价及真实多连接PostgreSQL负载测试。
