# 公网部署前清单

1. 准备一台有固定公网 IP 的服务器或云主机，绑定域名并配置 HTTPS 证书。
2. 在服务器设置 `.env.local` 中的 `SESSION_SECRET`（服务器上重新生成）、模型和服务密钥；不要把密钥写进前端或提交到代码仓库。
3. 使用 `docker compose up -d --build` 部署，反向代理只转发 443 到容器 3000，并转发 `X-Forwarded-Proto` / `X-Forwarded-For`。
4. 确认 `data/` 目录已挂载为数据卷，并做一次备份与恢复演练（见 `部署说明.md` 第四节）。
5. 用 `scripts/create-user.mjs` 建教师账号，不使用任何演示账号；启用日志轮转与定期数据库备份（登录限流已内置）。
6. 先用 3—5 个测试账号验收登录、积分原子扣减、异常重试、数据导出和权限隔离，再开放给学生。
7. 真实学生名单确认并取得同意后，再上传 `学生名册模板_120人.csv`；导入时勾选“每人随机临时密码”，下载凭据表后逐人私发。
8. 论文中的样本量、统计结果和图表在真实数据完成前保持原样。
