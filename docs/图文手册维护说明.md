# 图文手册维护说明

线上入口为 `/guide`，保留首页原有使用说明入口。

- `web/lib/user-guide.ts` 保存章节正文，`guide-walkthrough.ts` 保存操作步骤、图示说明和核对提示。
- `web/lib/guide-markdown.ts` 同时用于网页下载和文档生成，避免两份手册不同步。
- 在 `web` 目录运行 `pnpm guide:generate`，会核对章节入口、步骤和图片文件，并更新用户使用手册。
- `web/public/guide/` 的 login、cases、templates、expert、defense、cockpit 为2026年10月8日本地实际项目界面截图，未登录、未调用AI、未填写凭据；成长星图使用2026年9月28日真实测试界面裁切图，已去除身份区域。页面已说明记录因账号而异。
- 更新截图时不得包含账号、密码、密钥或学生身份信息；保留图片路径或同步修改配置。下载的Markdown引用站点图片，需要联网查看。
