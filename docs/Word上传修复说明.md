# Word导出与上传

Word下载统一生成真正的`.docx`（Office Open XML），包括专家报告、答辩准备稿和其他使用公共下载方法的入口。文件名不再追加`.doc`或产生双扩展名。

`mammoth`由开发依赖改为生产依赖，锁文件同步更新，确保Docker生产依赖安装包含DOCX解析库。上传按文件扩展名选择解析器，避免错误的浏览器MIME类型把DOCX二进制当作纯文本。

部署需重新构建镜像并更新服务。以前下载的HTML格式`.doc`文件，请用Word/WPS打开并另存为真正的`.docx`再上传，或使用新版重新导出。不能只改后缀。损坏、加密或非标准文件无法解析时会提供重新另存的提示。

自动化验证包括浏览器下载方法所用的DOCX生成器与上传解析器的往返测试，覆盖中文标题、章节、列表、表格；同时验证测试记录导出DOCX的回传解析和损坏文件提示。
