# 星创伙伴图文使用手册

建议体验路线：登录 → 案例与模板 → 创业星舰 → 专家打磨 → 模拟答辩 → 成长复盘。

## 虚拟演示材料

【虚拟演示项目】我们计划开发校园实验器材预约与共享工具，服务课程项目学生和实验室管理员，展示可预约时段、培训要求和借还状态。目前只有初步想法，尚未完成用户访谈，没有收入、专利或测试数据。请区分已知信息与待验证假设，指出主要问题，提出一周内可执行的访谈和原型测试计划，不要虚构应用成效。

## 1. 第一次使用

首页顶部点击“用户使用说明”即可打开本手册，无需登录，也不消耗积分；页面左下角也可随时打开手册或积分中心。使用AI功能前，用学校分配或已注册的学号登录，通过首页星球进入学习与应用模块。登录后每天自动获得30积分，未到账可在积分中心重试。不要在公共电脑保存个人API密钥。

1. 点击“打开对应页面”，使用组织方提供的测试账号和密码登录。账号填写在学号输入框。
2. 返回首页，通过星球进入模块；也可以直接使用本手册各章节的页面入口。
3. 首次体验建议先浏览免费案例与模板，再进行AI生成。账号密码由组织方单独提供。

结果核对：登录后能进入个人记录和积分中心；不要将他人的账号或真实学生信息输入演示材料。

## 2. 阅读与恢复界面

默认阅读模式提高背景亮度、文字对比度和常用控件字号。点击左下角“恢复原星空”即可恢复原始配色，再点“开启阅读模式”重新启用；选择保存在当前浏览器。不改动知识图谱构建、星球导航与原有学科辅导。

1. 首页星球用于选择学习与应用模块；进入子页面后可点击“返回星图”回到首页。
2. 使用左下角阅读模式按钮调整对比度；按浏览器 Ctrl / Command + 加号放大文字。
3. 若要恢复原始效果，点击“恢复原星空”；手册可随时重新打开。

结果核对：页面显示调整保存在当前浏览器，不会改动项目内容。

[打开对应页面](https://cxcy.tokenone.work/)

## 3. 案例宝库

上半部分是往届获奖项目，可按名称或产业筛选，查看教学摘要、项目来源、获奖依据和站外路演视频。合集不等同于每个项目独立视频，可能需要登录视频平台。下半部分保留课程区域产业案例及AI问答，需登录；没有课程数据时仍可读上方获奖项目。

1. 先按项目名称或产业关键词筛选，打开一个案例阅读教学摘要。
2. 分别查看项目来源与获奖依据，确认事实，再访问路演视频链接。
3. 记录可借鉴的用户问题、解决方案与验证方法，整理自己的项目思路。

结果核对：形成自己的案例分析；站外视频可能要求平台登录，案例摘要不代表获奖项目完整商业计划书。

## 4. BP、路演、专利与合同模板

先展开基础教学模板，按提示填写，再点击下载Word，用Word/WPS继续编辑。BP按用户、方案、证据、商业模式、团队和财务整理；路演模板包含300秒排练安排。专利交底及合同讨论稿用于教学准备，正式办理请使用附带的官方入口并请专业人员核对。课程扩展模板与AI指导仍在下半部分。

1. 选择BP、路演、专利交底或合同讨论模板，展开查看栏目。
2. 按栏目准备已有事实，将尚无证据的内容标为“待验证”。
3. 下载Word，在Word或WPS中填写；将整理好的摘要用于后续专家打磨。

结果核对：得到可编辑文档。下载模板本身不等于自动完成项目或取得专利、合同效力。

## 5. 创业星舰与熊猫主席

创业星舰将项目目标、专家协作、统筹成稿与继续打磨放在同一工作台。熊猫主席负责统筹，职能搭子分别提供战略、产品、技术、商业、产业、成长与材料建议。

1. 先了解甲板上的角色分工，由“熊猫主席”统筹，各职能搭子提供不同角度的建议。
2. 填写项目名，在目标输入框说明用户、问题、已有方案、证据和希望修改的部分。
3. 按页面提示启动协作，阅读各搭子的过程输出，等待统筹整理成稿。
4. 检查成稿中的事实、数字与假设；下载材料，或在继续打磨区输入具体修改意见。

结果核对：获得协作讨论与BP草稿。首次体验可只用一个小项目，切勿将AI补充的假设当作已发生的业务事实。

## 6. 专家打磨：从摘要到报告

在一键生成区填写30—12000字项目材料，包含用户、问题、方案、证据和困难，点击生成完整报告。报告包含诊断、改写摘要、待核验清单和下一周行动。成功后自动保存并可下载Word或Markdown；下方保留逐题专家对话。报告每份5积分，失败退还；个人API Key不扣平台积分。

1. 在“一键生成”区域粘贴30—12000字项目材料，可使用本页的虚拟案例。
2. 点击生成完整报告，等待返回，不要连续重复提交。
3. 阅读诊断、改写摘要、待核验事项与行动建议，优先处理证据缺口。
4. 下载Word或Markdown；若要追问具体问题，使用下方专家对话区。

结果核对：报告生成和逐题对话是两个入口；保存后可在“我的测试记录”找回。

## 7. 模拟答辩：准备与练习

选择赛道组别，一键生成区输出开场陈述、10个问题、回答框架和追问，属于准备稿，不给未发生的答辩打分。下方对话区进行真实练习，完成至少3个实质回答后请求评价。缺少维度的评分不补零。切换赛道会重置当前练习，请先导出或从历史记录查阅。

1. 先选择对应赛道或组别，再在准备稿区域输入项目材料。
2. 生成并阅读开场陈述、问题与回答框架，准备稿用于排练。
3. 在下方答辩对话区回答问题，完成至少3个实质回答后请求评价。
4. 查看有依据的维度反馈，再到成长星图复盘；切换赛道前先保存或导出。

结果核对：准备稿不等于完成答辩，也不会自动成为评分记录。不要把示例或缺失评分当成真实成绩。

## 8. 成长星图怎么看

先看选题、初稿、专家、答辩四步的产出状态；再选同类答辩对比组，查看最近得分、满分、得分率和较首次变化（百分点）。只比较相同赛道、项目标识与维度满分的记录。单次测评不显示进步；缺少记录不是0分。点下方带名称的星星回放内容，AI评价仅供学习参考。

1. 先读四个阶段的产出状态，确认自己完成了哪一步。
2. 若有多次可比答辩记录，再选择同类对比组，查看分数与变化。
3. 点击里程碑或对应测试记录回放原文，结合建议确定下一步行动。

结果核对：星星表示符合条件的里程碑，不代表分数。无记录不是0分；只有一次测评时不能据此判断进步。

## 9. 找回测试与课堂记录

我的测试记录保存普通练习和报告全文，支持继续练习及已有导出功能。成长星图只收录满足条件的里程碑，不能替代全部测试记录。课堂实验按教师开放的流程进入；实验进行中报告生成功能暂时不可用，避免干扰独立前后测，完成并退出实验后再使用普通模块。

1. 进入“我的测试记录”，查找对应模块和时间的记录。
2. 打开记录查看问答或报告全文，使用页面提供的继续练习、导出功能。
3. 课堂实验按教师开放的流程操作；完成并退出实验后再体验普通报告生成。

结果核对：测试记录用于找回内容，成长星图用于阶段复盘，两者用途不同。

[打开对应页面](https://cxcy.tokenone.work/me/records)

## 10. 积分用完怎么办

每天北京时间0点起可领取一次登录奖励30分，再提交80—2000字真实学习反思获得10分（每天一次，不可重复提交相同内容）。反思不公开，不开设论坛。普通文本问答每次1分，完整报告每份5分，语音每次1分，其他操作看模块提示；免费阅读和模板下载不受积分影响。积分中心可查看最近100条收支。

1. 在积分中心查看当前余额和最近收支，核对奖励与消耗。
2. 按页面提示领取每日奖励或提交自己的学习反思。
3. 若报告请求中断，先用同一请求重试核对结果；明确失败后再新建请求。

结果核对：保存请求编号便于管理员排查。以页面流水为准，阅读案例与下载基础模板不受积分余额影响。

[打开对应页面](https://cxcy.tokenone.work/me/credits)

## 11. 生成失败与重复提交

1. 在积分中心查看当前余额和最近收支，核对奖励与消耗。
2. 按页面提示领取每日奖励或提交自己的学习反思。
3. 若报告请求中断，先用同一请求重试核对结果；明确失败后再新建请求。
